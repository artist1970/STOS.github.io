What it is

A workbench for sovereign computing.

STOS brings terminal work, repositories, search, guided diagnostics, coding education, and AI-assisted operations into one coherent workspace. The public page describes the platform without exposing protected internals, credentials, private infrastructure, or sensitive security implementation.

Build openly where possible. Protect authority where necessary.
Four public pillars

One environment, several disciplines.

STOS is being developed as more than a terminal UI. Its major public-facing parts are meant to work together as a unified development and learning platform.

STOS Workbench

A dynamic terminal workspace with persistent sessions, terminal tabs, searchable history, repository context, print-ready records, protected terminals, and adaptable layouts.

Terminals Search Diagnostics Device-aware

Sovereign Forge

A Git-based internal forge for repositories, version history, branches, issues, pull requests, reviews, releases, and future local automation.

Git Branches Pull Requests Issues

STOS AI

A policy-aware guide for commissioning, coding, debugging, technical explanation, guided workflows, and safe recommendations. Sensitive actions remain subject to authentication, authorization, policy, and human approval.

Guide Mode Operator Mode Diagnostics Human approval

Khaemenes Academy

A coding and systems learning environment designed around real tools, isolated student workspaces, repositories, guided terminals, assignments, progressive hints, and authentic development workflows.
