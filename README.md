# STOS Public Portal

This repository is the **public-facing home of STOS**.

It exists so people can understand what STOS is, what it is being built to do, how the public-facing parts fit together, and where future downloads and public documentation will live.

## Public pillars

- **STOS Workbench** — terminal workspace, search, diagnostics, repository context
- **Sovereign Forge** — Git-based repositories, branches, issues, pull requests, releases
- **STOS AI** — guided commissioning, coding help, diagnostics, policy-aware recommendations
- **Khaemenes Academy** — real coding and systems learning inside isolated environments

## What does not belong here

Do not publish:

- production credentials
- private keys
- master keys
- gateway/admin tokens
- private CORE material
- protected runtime topology
- private recovery packages
- internal secret-bearing configuration
- private student data

## Future download center

When STOS is ready for public distribution, this repository can host or link to:

- platform packages
- release notes
- checksums
- signatures
- installation guides
- compatibility information
- public security notices

The public portal should remain informative without becoming an operational blueprint for protected infrastructure.
